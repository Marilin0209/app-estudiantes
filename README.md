# 📌 Proyecto: App de Estudiantes

Este es un proyecto de Gestion de estudiantes desarrollado con **React + Vite** y **Material UI**.  
Incluye un menú lateral (drawer) con navegación y páginas para \*_agregar, modificar y eliminar estudiantes_.

---

## 🚀 Requisitos

- Tener instalado **Node.js** (versión 16 o superior).
- Tener instalado **npm** (se incluye con Node).

---

## ⚙️ Instalación

1. Descomprimir el archivo `app-estudiantes.zip`.
2. Abrir la carpeta del proyecto en la terminal.
3. Instalar las dependencias con:
   ```bash
   npm install
   ```
   ▶️ Ejecutar el proyecto

En la terminal, dentro de la carpeta del proyecto, correr:
npm run dev

Esto abrirá la aplicación en tu navegador en:
http://localhost:5173

📂 Estructura del proyecto

src/ → Contiene el código principal de la aplicación.

components/ → Componentes reutilizables (ej: MenuDrawer).

pages/ → Páginas principales (Agregar, Modificar, Eliminar, etc).

App.jsx → Configuración principal de rutas y tema.

public/ → Archivos públicos.

package.json → Lista de dependencias del proyecto.

✨ Funcionalidades

Navegación con menú lateral.

Formulario para agregar tareas.

Opciones para modificar y eliminar.

Diseño con Material UI y tema personalizado.
